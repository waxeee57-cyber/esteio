# ESTEIO

Production demo website for a Lisboa industrial B2B brand: scaffolding, temporary structures, and modular site buildings.

Built as a Next.js App Router equivalent of an urgent Freelancer WordPress package — stronger identity, specification tables, quotation path, and a 24-page catalogue sample. WordPress CMS handoff is available if the client needs an editor; this repo is the design-and-sales system.

## Brand

**ESTEIO** (Portuguese: prop, strut, stay) — Esteio Sistemas Industriais, Lda., Sacavém / Lisboa.

Dark steel `#0A0D10`, plate `#161B22`, concrete text `#E6E1D6`, safety orange `#E85A17` (load line only). Display: Barlow Condensed. Body: Source Sans 3. Specs: IBM Plex Mono.

Guidelines live at `/brand`. Logo mark: `public/logo.svg` and `src/components/logo.tsx`.

## Run locally

```bash
npm install
npm run generate:catalogue
npm run dev
```

App: [http://127.0.0.1:4321](http://127.0.0.1:4321)

```bash
npm run build
npm run start
npx tsc --noEmit
```

No `.env` required. The quotation API is mock-only and returns a reference number without a database.

## Page map

| Path | Purpose |
| --- | --- |
| `/` | Home — metrics, three families, standards |
| `/products` | Category index |
| `/products/scaffolding` | Façade, ring-lock, towers, weather decks + specs |
| `/products/structural` | Props, heavy towers, beams, loading platforms + specs |
| `/products/modular` | Offices, welfare, sanitary, workshops + specs |
| `/applications` | Six Portuguese site types |
| `/catalogue` | 24-page cover system + PDF download |
| `/catalogue/print` | Printable HTML export |
| `/about` | Timeline + Sacavém yard map |
| `/quote` | Quotation form + WhatsApp desk |
| `/brand` | Mark, colour, type, voice |

Sticky WhatsApp CTA on every page (`+351 21 000 4480`, placeholder). Catalogue PDF: `public/catalogue/esteio-systems-catalogue-2026.pdf` (regenerated by `npm run generate:catalogue`).

## Handoff

This demo is Next.js (TypeScript, Tailwind, shadcn/ui). A WordPress migration (custom theme or headless) can follow the same IA, brand tokens, and quotation fields if the client requires wp-admin.
